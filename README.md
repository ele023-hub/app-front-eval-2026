# Examen du cours d'approche front-end 2026

Projet réalisé dans le cadre d'un examen d'approche front-end. L'objectif était de reproduire une page fournie en vidéo de démonstration, en HTML, CSS (Tailwind via Vite) et JavaScript. Tout en intégrant de façon autonome cinq librairies JS imposées — sans les coder soi-même.

## Structure de la page

- Navigation permettant de passer d'une section à l'autre
- 5 sections, chacune intégrant une librairie JS distincte :
  - **Swiper** — carrousel
  - **ScrollReveal** — animations au scroll
  - **Typed.js** — effet de texte animé
  - **Chart.js** — graphique
  - **SweetAlert2** — alertes stylées
- Footer

## Stack

- HTML / CSS / JavaScript
- Tailwind CSS (intégré via des directives, dans des fichiers séparés plutôt que dans l'index)
- Vite

## Contexte

Consigne fournie sous forme de vidéo (pas de cahier des charges écrit) : reproduire le rendu final attendu, chaque section devant intégrer la librairie imposée avec son propre style.
